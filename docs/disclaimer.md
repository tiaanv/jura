## Remote controls and overrides

Remote controls and automations can start machine operations. Before issuing
a command, ensure the machine is safe to operate, an appropriate container is
in place, and nobody is exposed to moving parts, steam, or hot liquids.

Manual overrides require particular care. Enabling the Cool Control override
intentionally reports a healthy cooler state and bypasses milk-specific brew
checks, including when the actual cooler is empty, offline, or unavailable.
The override can persist across device restarts. You are responsible for
checking the milk supply, supervising operation, and disabling the override
when it is no longer needed.
